# QA-04 multilingual and AI quality review

QA-04 is the pre-launch quality gate for the seven supported languages. It
uses the versioned golden fixture from LANG-02 and records only bounded review
metadata: language, niche, platform, model/prompt version, scores, flags and
outcomes. Raw prompts and output text are not written to the quality report.

The gate evaluates:

- language fidelity and expected script for Hindi, Hinglish, Bhojpuri, Punjabi,
  Haryanvi, Telugu and Kannada;
- representative niche/platform contexts;
- mixed-language and script-mismatch regressions;
- unsupported-claim review flags;
- 30–60 second duration compliance;
- safety allow/review/reject cases;
- two-reviewer scoring across fidelity, naturalness, platform fit, safety and
  unsupported claims.

Run locally with:

```sh
npm run test:qa04
npm run qa04:review
```

The review command writes `.ci-artifacts/qa04-quality-review.json` and exits
non-zero when a configured threshold, safety expectation or human-review rule
fails. CI retains the report and log for 14 days. A `no-go` result means the
affected output must remain in review or rejected state; it must not silently
appear as a clean publishable draft.
