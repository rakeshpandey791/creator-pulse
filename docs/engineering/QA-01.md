# QA-01 test suites

QA-01 is the continuous quality gate for the modular monolith. The default
`npm run check` command runs deterministic unit and service-contract tests,
type/lint/format checks, language evaluation, architecture checks, secret
detection, Compose validation and CI configuration checks.

## Test layers

- **Unit/domain:** identity, creator profile, research normalization and
  feasibility, scoring, recommendations, safety, language, AI schemas and
  credit ledger behavior use deterministic fakes and controlled clocks.
- **Integration/service:** repository ownership, Mongo-shaped persistence,
  discovery/materialization, generation queues, feedback, commercial flows,
  controller boundaries and safety routes are covered without external
  providers.
- **API contracts:** `tests/qa01-api-contracts.test.ts` inspects Nest route
  metadata and fails when a required method/path disappears or duplicates.
- **Database/Compose:** `npm run test:db` validates migration, seed,
  validators, indexes and integrity against the Mongo service; Compose smoke
  checks provider-safe defaults.
- **Coverage:** `npm run test:coverage` publishes text, JSON summary and HTML
  V8 reports in `coverage/`. CI retains them with the quality artifacts for 14
  days.

## Local commands

```sh
npm run check
npm run test:coverage
npm run test:db
```

External provider calls are not used by the deterministic suite. Browser E2E
and visual regression belong to QA-02 and are intentionally not part of QA-01.
