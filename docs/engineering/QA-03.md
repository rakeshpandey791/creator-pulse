# QA-03 performance, resilience and cost baseline

QA-03 is a deterministic release baseline for the MVP’s bounded work paths.
It does not call paid providers or require a browser, MongoDB, or Redis service.
The production-like database and queue smoke tests remain in the Compose gate.

## Release controls

| Area                           |                 Target | Evidence                                                 |
| ------------------------------ | ---------------------: | -------------------------------------------------------- |
| Provider p95 latency           |             ≤ 5,000 ms | AI POC thresholds and `.ci-artifacts/qa03-baseline.json` |
| Provider failure rate          |                  ≤ 10% | AI POC threshold evaluation                              |
| Provider retry rate            |                  ≤ 25% | AI POC threshold evaluation                              |
| Provider concurrency           |       ≤ 2 active calls | `tests/qa03-resilience.test.ts`                          |
| Per-user/global request budget |                10 / 20 | `tests/qa03-resilience.test.ts`                          |
| Credit overspend               |                      0 | Concurrent ledger reservation test and baseline          |
| Duplicate settlement           | 0 extra ledger entries | CR-02 and QA-03 retry tests                              |

The deterministic harness explicitly exercises provider timeout retries, quota
exhaustion, bounded concurrency, credit contention, duplicate settlement and
worker-retry behavior. The JSON report records targets, observations and a
go/no-go decision; CI retains it for 14 days.

## Commands

```sh
npm run test:qa03
npm run qa03:baseline
```

The baseline uses the fake provider even when local environment variables are
configured, so the result is reproducible and cannot incur provider cost.
Live Mongo/Redis slowdown and outage checks belong to the Compose/infrastructure
release environment and must be attached separately before production launch.
