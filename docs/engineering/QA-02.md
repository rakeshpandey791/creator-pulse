# QA-02 full journey and UI regression

QA-02 provides the release-gate browser suite for the creator journey. The
tests use deterministic API route fixtures, so they do not depend on another
creator, live providers, or mutable research data.

Coverage includes:

- signup → four-step onboarding → personalized Today feed;
- actionable invalid-input recovery;
- direct-publishing absence from the MVP journey;
- Playwright Axe accessibility scanning;
- desktop/mobile visual regression assertions for the authentication Stitch
  reference;
- existing Library status, pagination, error, and mobile-flow coverage.

Run the journey suite with:

```sh
npm run test:e2e:qa02
```

Run all browser suites with:

```sh
npm run test:e2e
```

Visual assertions are opt-in because Stitch baselines require explicit product
owner review. The release QA environment runs them with
`RUN_VISUAL_REGRESSION=1` after approving the generated snapshots. Browser
execution is intentionally separate from the unit/contract gate and is not
run by `npm run check`.
